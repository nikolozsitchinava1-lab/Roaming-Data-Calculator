## Brand & Style

This design system unites the nostalgic romance of tactile travel ephemera with the surgical clarity of contemporary global telecom utilities. Designed for international travelers navigating data anxiety, the experience transforms complex megabyte calculations into an empowering, transparent planning ritual.

### Emotional Response & Personality
- **Reassuring Precision:** Eliminates "bill shock" through transparent breakdowns, visible safety buffers, and clear cost caps.
- **Wanderlust & Keepsake Warmth:** Balances high-tech utility with tactile postcard physicalism—stamped borders, crisp paper-like white tiles, and subtle tinted depths.
- **Effortless Mastery:** Provides responsive interactive controls (segmented profile steppers, granular day-slider gauges, and instant eSIM plan matching) that make data estimation feel playful rather than punitive.

### Design Style: Modern Utility with Tactile Souvenir Micro-Accents
The visual grammar merges modern SaaS ergonomics with fine physical finishes. Crisp white surfaces sit upon delicate lavender-tinted wash canvases, bounded by tailored deep slate/indigo hairline strokes. Key conversion elements utilize the electric intensity of brand violet tones, grounded by deep twilight navy for authoritative data displays.

## Colors

The palette directly honors the brand palette while expanding functional surface tiers to power dense data interfaces without visual fatigue.

### Core Roles
- **Primary (`#5D3BE0` - Electric Indigo):** Anchors primary call-to-actions, active slider tracks, selected profile states, and key metric badges.
- **Secondary (`#9E5AFD` - Hyacinth Blue):** Used for interactive hover highlights, secondary action accents, gradient endpoint transitions, and progress bar fills.
- **Tertiary (`#3C2F80` - Twilight Blue):** Acts as the foundational anchor for prominent headers, chart legends, container border accents, and high-emphasis metric copy.
- **Neutral (`#231B42` - Nightfall Slate):** High-legibility text neutral that keeps body copy warm and sharp without resorting to pure charcoal.

### Surface and Functional Hierarchy
- **Canvas Base (`#F8F7FD`):** Soft, atmospheric lavender tint evoking smooth unprinted postcard stock.
- **Subtle Container (`#F0EDFB`):** Enclosed recessed groups such as calculator breakdown tables, slider track backdrops, and filter chips.
- **Pure White (`#FFFFFF`):** High-elevation elevated cards, interactive inputs, and active tooltips.
- **Buffer Accent (`#2DD4BF`):** Dedicated turquoise token to visually distinguish the "+20% Safe Roam Buffer" from standard data usage metrics.

## Typography

Typography relies uniformly on the brand's primary sans-serif family, calibrated for rigorous metric presentation and responsive layout switching.

### Editorial & Display Hierarchy
- **Data Callouts:** Primary GB tallies and total bundle recommendations leverage `display-lg` with tight tracking to mimic digital stamp ledgers.
- **Contextual Headings:** Section titles combine structural weights (`700` and `600`) with Twilight Blue tinting for authoritative, clean rhythm.

### Numerical Data Treatment
All numerical readouts in sliders, breakdown summaries, and pricing tiers should render with `font-variant-numeric: tabular-nums;`. This prevents layout shifts during interactive adjustments.

## Layout & Spacing

The layout model is anchored by a structured 12-column responsive fluid grid on desktop, transitioning to 8 columns on tablet, and a 4-column compact flow on mobile.

### Layout Rhythms
- **Desktop (min-width: 1024px):** Max container width of `1280px`. Left column (7 cols) houses interactive profile controls, toggles, and usage steppers; right column (5 cols) acts as a sticky recommendation dossier containing data gauges, safety margins, and instant eSIM tier conversion cards.
- **Tablet (768px – 1023px):** Fluid multi-column with stacked summary sheets (`gutter`: `1.25rem`, `margin`: `2rem`).
- **Mobile (under 768px):** Linear vertical progression. Sticky bottom summary bar pins calculated total GB, buffer pill, and direct checkout trigger.

### Spatial Spacing Token Usage
- `space-xs` (4px): Icon-to-text gaps in meta badges and unit tags (e.g., "GB / day").
- `space-sm` (8px): Gaps between profile chip selectors and stepper action buttons.
- `space-md` (16px): Internal padding for modular calculation blocks and segmented switch rows.
- `space-lg` (24px): Card interior padding and separation between modular input groups.
- `space-xl` (40px): Section breaks and header-to-calculator content transitions.

## Elevation & Depth

Visual depth is achieved through ambient, cool-indigo tinted shadow diffusion paired with precise hairline perimeter strokes, avoiding generic gray box-shadows.

### Elevation Hierarchy
- **Level 0 (Flat / Recessed):** Canvas `#F8F7FD` and nested breakdown slots (`#F0EDFB`). Flat with optional inner border `1px solid #E2DCF7`.
- **Level 1 (Card & Modular Tiles):** White cards (`#FFFFFF`) with a dual-layer ambient shadow:
  `0 2px 8px -2px rgba(60, 47, 128, 0.06), 0 1px 3px 0 rgba(93, 59, 224, 0.04)` bordered with `1px solid #E2DCF7`.
- **Level 2 (Interactive Floating Elements & Selected States):** Selected eSIM recommendation cards and active profile tiers:
  `0 8px 24px -4px rgba(93, 59, 224, 0.14), 0 2px 6px -1px rgba(60, 47, 128, 0.06)` with a `1.5px solid #5D3BE0` active rim.
- **Level 3 (Sticky Ledger Sheets & Modals):** Pinned summary ledger and country selection drawers:
  `0 16px 40px -8px rgba(35, 27, 66, 0.16)`.

## Shapes

The design system adopts a balanced rounded geometry (`roundedness: 2`, standard radius of `0.5rem / 8px`). This preserves clean, modern UI performance while offering friendly, accessible touch points.

### Radius Assignments
- **Input Fields, Steppers, & Sliders:** `0.5rem (8px)` for compact and responsive touch targets.
- **Interactive Preset Chips & Status Tags:** `rounded-full (9999px)` pill format to reinforce touchability and quick toggling.
- **Primary Content Cards & Data Panels:** `rounded-lg (1rem / 16px)` evoking modern structural cards with clean silhouettes.
- **Hero Comparison & Recommended eSIM Dossier:** `rounded-xl (1.5rem / 24px)` to emphasize destination containers.

## Components

### Buttons & Action Triggers
- **Primary ("Select eSIM Plan"):** Electric Indigo (`#5D3BE0`) fill, pure white label, `rounded-md`, minimum height `48px`. Hover triggers a rich deepening to `#4E2EC7` with a subtle elevation shift.
- **Secondary / Stepper Controls:** Recessed lavender container (`#F0EDFB`), Twilight Blue text (`#3C2F80`), `border: 1px solid #E2DCF7`.
- **Tertiary / Link:** Ghost styling with bottom underline indicator transitioning on hover.

### Interactive Sliders & Steppers
- **Data Volume Sliders:** Thick track (`8px`) in `#F0EDFB` with an active fill of `#5D3BE0`. The handle thumb is an oversized 24px pure white disc with a `3px solid #5D3BE0` rim and Level 2 elevation shadow, featuring haptic/tooltip feedback on drag.
- **Numeric Counter Steppers:** Three-part pill module ([-] [Value] [+]) with twilight icon buttons that disable visually at defined minimum bounds.

### Selectable Persona & Trip Cards
- **Deselected State:** Pure White background, `1px solid #E2DCF7`, muted slate metadata.
- **Selected State:** Lavender wash background (`#F0EDFB`), active border `2px solid #5D3BE0`, with an Electric Indigo check badge pinned in the top-right corner.

### Data Visualization & Safe-Buffer Meter
- **Dual Progress Bar:** Segmented bar displaying "Expected Base Usage" in solid Electric Indigo (`#5D3BE0`) seamlessly adjoining the "+20% Safe Roam Cushion" styled in mint turquoise (`#2DD4BF`) with fine diagonal hash marks.
- **Metric Badges:** Crisp pill tags displaying data allocation (e.g., `12.4 GB Recommended`) in high-contrast Twilight Navy text over Lavender surfaces.

### Input Fields & Search Bars
- **Country / Destination Selector:** White background, `1px solid #E2DCF7`, left-aligned globe icon in Twilight Blue, and interactive dropdown affordance. On focus: glow ring `0 0 0 3px rgba(93, 59, 224, 0.2)` with border color shifting to `#5D3BE0`.

### eSIM Package Recommendation Cards
- **High-Trust Layout:** Highlighted with a top ribbon tag ("Best Value for 14 Days"), bold headline gigabyte allowance, network speed indicators (5G/LTE), local carrier logos, and instant QR-activation guarantees.
